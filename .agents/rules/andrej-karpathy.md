# Andrej Karpathy Engineering Rules

1. **Think Before Coding**: Explicitly surface tradeoffs, state assumptions, and ask whenever requirements are ambiguous.
2. **Simplicity First**: Write the minimum, most concise code to solve the problem. Avoid over-engineering, unasked abstractions, and speculative features.
3. **Surgical Changes**: Make minimal, precise changes to target files without altering unrelated code, formatting, or comments.
4. **Goal-Driven Execution**: Define clear verification criteria and ensure `npm run build` and runtime behaviors pass with zero errors.
